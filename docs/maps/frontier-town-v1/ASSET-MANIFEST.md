# Asset Manifest — frontier-town-v1

สถานะ: asset เมืองถูกโหลดและวางใน prototype scene `src/frontier-town-map.ts`; ตำแหน่งอ้างอิงตาม LOCAL-MAP-BRIEF.md

## สเกลและวิธีอ่านขอบเขต

ตัวละครใน runtime ปัจจุบันใช้ชุด run 1254 × 1254 px แสดง 110 × 110 px และ origin (627,1180). ฉากเมืองตั้ง 1H = 110 world px เพื่อให้ได้แผนที่ 5280 × 3520 px จากสมมติฐานขนาด 48 × 32H; ค่า H เป็นสเกลประกอบฉาก ไม่ใช่ alpha height ที่ยืนยันของ run sprite.

ขนาดแสดงจริงในตารางคำนวณจาก `s = min(กรอบกว้าง/visible-width, กรอบสูง/visible-height)` แล้วคูณขอบเขต alpha ด้วย s; วัตถุ runtime ใช้ alpha center/bottom เป็น anchor เพื่อยึดกับพิกัดฐานที่ระบุ.

ตารางด้านล่างระบุไฟล์, มิติภาพต้นฉบับ, alpha bounds [left,top,right,bottom) ที่ alpha ≥128, และขนาดแสดงผลสูงสุดที่เสนอเป็น H. คง aspect ratio โดยปรับให้พอดีกับกรอบเป้าหมาย; อย่าปรับภาพให้บิดเพื่อให้เต็มกรอบ. สิ่งปลูกสร้าง/วัตถุยึดฐานล่างกึ่งกลางเป็นข้อเสนอสำหรับการประกอบฉาก. ขนาดกรอบเป็นข้อเสนอ ไม่ใช่ค่าที่ทดสอบในเกม.

## การตรวจไฟล์ที่ทำแล้ว

- PNG ของ prop และอาคารมี alpha transparency; bounds ในตารางเป็นกรอบวัตถุจากการตรวจ alpha ≥128 ไม่รวมพื้นที่ว่างรอบภาพ. Texture ทั้งสี่เป็นภาพทึบ.
- ภาพต้นไม้ทำเป็นชิ้น trunk และ canopy แยกกัน; ต้องปรับตำแหน่งซ้อนทับก่อนใช้จริง.
- รุ่นแรกที่มีแสงฝังถูกเก็บไว้ในชื่อ `props/A11-northeast-warp-gate-baked-glow-unused.png` เพื่อไม่ให้หยิบไปใช้ผิด; asset หลักชื่อ `A11-northeast-warp-gate.png` เป็นกรอบประตูไม่มีเงาทอด/เอฟเฟกต์ ร่วมกับ `A21-warp-shimmer.png` ที่แยกเอฟเฟกต์แล้ว.
- ยังไม่ได้ตรวจ collision bounds หรือ clickable areas; collision และระบบ warp ไม่ได้เพิ่มใน camera prototype.
- ภาพ runtime แสดงที่สเกล 110 px/H; ไม่มีการ resample หรือแก้ไฟล์ต้นฉบับ. การตรวจครั้งนี้ไม่ถือเป็นการ review คุณภาพหรือรับรอง seam แบบละเอียด.
- ไฟล์สเกลใน `review/` เป็นภาพประกอบเพื่อวิจารณ์สัดส่วน ไม่ใช่การวัดจาก runtime.
- `review/scale-check-actual.svg` เป็นภาพวิจารณ์สัดส่วน ไม่ใช่หลักฐาน runtime; ภาพ asset ถูกแสดงใน Phaser ที่สเกลตาม layout แล้ว แต่ยังไม่ได้ทำ quality review หรือวัดความคมเชิงภาพอย่างเป็นระบบ.
- ตรวจค่าความต่างเฉลี่ย RGB ระหว่างขอบซ้าย/ขวาและบน/ล่างของ texture ต้นฉบับ: grass 12.2/11.2, road 13.3/15.4, plaza 6.5/6.7, river 6.6/8.5 (0–255). เป็นการตรวจพิกเซลขอบเบื้องต้น ไม่ได้ยืนยันว่า tile ต่อกันไร้รอยเมื่อปูในเกม; grass/road มีโอกาสเห็นรอยต่อมากกว่า.
- alpha ต่ำกว่า 32 ครอบคลุมราว 12.62% ของภาพ A21 (เอฟเฟกต์แสงแบบนุ่มโดยตั้งใจ); ปรับความทึบ/ขนาดของชั้นเอฟเฟกต์เมื่อประกอบจริงได้. ไฟล์ A11 รุ่นแรกมีบริเวณแสง alpha จางมากกว่ากรอบประตูรุ่นใหม่และถูกระบุเป็น variant ที่ไม่ควรใช้.
