# Image Generation Notes — frontier-town-v1

ภาพในชุดนี้สร้างด้วย image generation ตามแนวทางภาพที่เลือกไว้: crisp adventure-fantasy digital paint, clean silhouettes and edges, soft light, short shadows, distinct asset groups. ภาพอ้างอิงใช้พิจารณาระดับรายละเอียดและการจัดกลุ่มเท่านั้น ไม่คัดลอก UI, รูปร่างเฉพาะ, ชื่อ, ตัวละคร หรือผังจากเกมอ้างอิง.

## Prompt brief ที่ใช้ร่วมกัน

### Textures

สร้างภาพ tileable แบบมุมมองจากบนลงล่างสำหรับเกม fantasy town, ไม่มีตัวอักษร/วัตถุเด่น/ขอบกรอบ, ลวดลายอ่านง่ายเมื่อย่อ, แสงสม่ำเสมอและไม่มีเงาทิศทาง เพื่อใช้ปูซ้ำเป็นพื้นหญ้า, ถนนหิน, ลานกลางเมือง และผิวน้ำตามชื่อไฟล์.

### สิ่งปลูกสร้าง

สร้างอาคารเดี่ยวสำหรับเกม fantasy town ในภาพวาดดิจิทัลคมชัด ขอบสะอาด silhouette ชัด, มองเห็นทั้งอาคาร, ไม่มีฉากหลังและไม่มีพื้น/เงาทอดยาว, พื้นหลังโปร่งใส, ไม่ใส่ข้อความหรือผู้คน. แต่ละ prompt ระบุชนิดอาคารตามชื่อไฟล์: community hall, บ้านสามแบบ, community pavilion, workshop, watchpost.

### Props และ vegetation

สร้างวัตถุเดี่ยวแบบแยกชิ้นพื้นหลังโปร่งใส ไม่มีข้อความ/ฉากหลัง/เงาบนพื้น สำหรับน้ำพุ, waystone, route board, ประตูวาร์ป, lantern post, bench, ต้นไม้ trunk/canopy แยกกันสองคู่, shrub, flower cluster และ river stones. สัดส่วนและจุดยึดวัตถุปรับด้วยกรอบ H ใน manifest ไม่ใช่การยืดภาพ.

ประตูทางออกใช้กรอบหินล้วน เปิดช่องกลางโปร่งใส ไม่มีเงาทอดหรือแสง; สร้างชั้นพอร์ทัลแยกเป็น PNG โปร่งใสเพื่อปรับขนาดและ alpha ได้อิสระ.

### ภาพตรวจสัดส่วน

สร้างแผ่นเปรียบเทียบภาพอ้างอิงตัวละครเดิมกับสิ่งปลูกสร้าง/พร็อพ เพื่อดูความสัมพันธ์เชิงภาพพร้อมเส้นบอกขนาดและป้ายภาษาไทย. แผ่นนี้เป็นภาพสื่อสารที่ imagegen วาดขึ้นใหม่ ไม่ใช่การวัด pixel-accurate หรือหลักฐาน runtime.

## ข้อจำกัด

ไม่ได้บันทึก raw prompt รายคำแยกสำหรับทุกไฟล์ไว้ใน repo ขณะสร้าง; brief ข้างต้นสรุปคำสั่งร่วมที่ใช้กับแต่ละกลุ่ม. ไฟล์ภาพสุดท้ายเป็นผลที่ตรวจได้ในโฟลเดอร์ asset.
