# Local Map Brief — เมืองด่านธารา (frontier-town)

สถานะ: นำเข้าฉากเล่น prototype แล้ว โดยวางตามข้อสรุปที่ยืนยันและพิกัดประมาณใน brief

## ข้อสรุปที่ยืนยันจากบทสนทนา

- เป็นเมืองเกิดและแมปแรกของตัวละคร เป็นพื้นที่ปลอดภัยทั่วเมือง
- ใช้แนวทางภาพ B: ถนนวนเป็นวงรอบย่านกลางเมือง
- น้ำพุอยู่กลางลาน และจุดเกิดอยู่รอบน้ำพุ
- มีทางออกเมืองเดียวที่มุมตะวันออกเฉียงเหนือ เชื่อมไปแผนที่โลกหมายเลข 4 (สะพานเก่า)
- ชื่อที่ตกลงใช้: เมืองด่านธารา; รหัสโซน `frontier-town`

## สมมติฐานสำหรับการทำ asset และสเกล

รายละเอียดต่อไปนี้ถูกกำหนดเพื่อให้เตรียมไฟล์ได้ โดยยังไม่ได้รับการยืนยันเป็นตัวเลขในบทสนทนา:

- ขนาดอ้างอิง 48 × 32 หน่วยตัวละคร (H); runtime ใช้ 110 px/H ตามขนาดกรอบตัวละครปัจจุบัน จึงได้พื้นแมป 5280 × 3520 px. ค่า 48 × 32H และ 110 px/H เป็นสมมติฐานที่ใช้สร้างแมป ไม่ใช่มิติที่เคยยืนยันในบทสนทนา
- ขอบกล้องอ่านจาก `public/assets/maps/frontier-town-v1/layout.json` แล้วคำนวณจากพื้นเล่นเท่านั้น; ไม่รวมพื้นที่โปร่งใสหรือส่วนภาพ asset ที่ยื่นพ้นขอบ
- H เป็นหน่วยอ้างอิงใน brief; runtime กำหนด 110 px/H ตามกรอบ sprite ปัจจุบัน ไม่ได้อ้างว่าเท่ากับความสูง alpha ที่มองเห็นจริง
- จุดกึ่งกลางน้ำพุ (24,16); เสนอชุดจุดเกิดล้อมรอบน้ำพุ 6 จุดที่ (24,18), (21.5,16), (26.5,16), (24,13.5), (21.5,18), (26.5,18). ตำแหน่งย่อยและกติกาเลือกจุดยังเป็นค่าตั้งต้นสำหรับตรวจผัง ไม่ยืนยันว่าจะสุ่มหรือเลือกตามผู้เล่น
- ลานกลางประมาณ 8 × 6H; ถนนวงแหวนกว้างประมาณ 4H; ขอบเมืองเป็นเขตปลอดภัยทั้งหมด
- แนวลำน้ำ/คลองวางชิดขอบตะวันตกเฉียงใต้เป็นองค์ประกอบฉาก; ตำแหน่งและรูปร่างนี้เป็นสมมติฐานเพราะ World Map Brief ไม่ระบุขอบเขตน้ำระดับเมือง
- ประตูตะวันออกเฉียงเหนือวางใกล้ (43,5) และเป็นจุดเชื่อมออกสู่โซน #4 เท่านั้น ไม่เพิ่มทางเชื่อมอื่น
- จุดหมายภายในเมืองและพิกัดเป็นการจัดวางเบื้องต้นเพื่อประกอบภาพ ไม่ใช่ข้อสรุปเนื้อเรื่องหรือการออกแบบเควสต์

## การเชื่อมแผนที่โลกและเส้นทาง

สำหรับแมปเมืองนี้มีเพียงการเชื่อม `#1 เมืองด่านธารา ↔ #4 สะพานเก่า` ที่มุมตะวันออกเฉียงเหนือ ตามแผนที่โลกที่เลือกไว้ เส้นทางอื่นคงตามกราฟที่ผู้ใช้กำหนดไว้เดิม: 4 เชื่อม 2, 8, 5, 13; 8 เชื่อม 9, 10, 6; 5 เชื่อม 13, 12; 2–3; 3–5; 9–7; 6–7; 7–11; 11–12; 12–14; 13–14. ระดับแนะนำใช้แทนเงื่อนไขปลดล็อกตามคำยืนยันก่อนหน้า; ยังไม่มีตัวเลขระดับใน brief นี้.

## การวางพื้นผิว

| Texture | ขนาด tile อ้างอิง | หมายเหตุ |
|---|---:|---|
| `TX-GRASS-01` | 2H | หญ้าพื้นหลัก |
| `TX-ROAD-01` | 1H | ถนน/ทางเดินวงแหวน |
| `TX-PLAZA-01` | 1.5H | พื้นลานน้ำพุ |
| `TX-RIVER-01` | 2H | ลำน้ำ/คลอง |

ขนาด tile เป็นสมมติฐานเพื่อคุมขนาดลวดลาย; นำไปแสดงใน Phaser แล้ว แต่ยังไม่ได้ตรวจ seam แบบละเอียด.

## สถานะและขอบเขต prototype runtime

- ฉากเมืองด่านธาราและกล้องติดตามอยู่ใน `src/frontier-town-map.ts`; build ใช้ขอบพื้น 5280 × 3520 px ที่คำนวณจาก layout runtime.
- ระบบควบคุมตัวละครและแอนิเมชัน 8 ทิศที่ใช้ร่วมกันอยู่ใน `src/traveler-controller.ts`; แมปใหม่โหลด asset/ลงทะเบียน animation ผ่าน helper เดียวกัน แล้วส่งขนาดขอบเขตเฉพาะแมปให้ controller.
- อาคารและพร็อพมี collision เฉพาะแถบบริเวณฐาน เพื่อให้ตัวละครเดินไปอยู่หลังภาพสิ่งปลูกสร้างได้โดยไม่เดินทะลุฐาน; เสาไฟ ดอกไม้ เรือนยอด และเอฟเฟกต์ประตูเดินผ่านได้. ยังจำกัดการเดินด้วยขอบเขตแมป.
- ประตูทางออกมี trigger ไป scene key `old-bridge` และส่ง spawn id `from-frontier-town`; โปรเจกต์ยังไม่มี scene ปลายทาง จึงแสดงข้อความว่าแมปยังไม่พร้อมแทนการเปลี่ยนฉาก.
- จุดเริ่มต้นใช้ (24,18)H ซึ่งเป็นหนึ่งในตำแหน่งรอบน้ำพุที่เสนอไว้; ยังไม่มีระบบสุ่ม/เลือกจุดเกิด.
- ตรวจภาพกล้องที่ตำแหน่งกลางและมุมทั้งสี่ด้วยจุดเริ่มทดสอบชั่วคราวบน viewport 320 × 700 px; พื้นแมปเต็ม viewport เมื่อกล้องชนขอบและไม่เห็นพื้นที่ว่างนอกพื้น. คืน spawn เป็น (24,18)H หลังทดสอบ.
- ตรวจบริเวณหอเฝ้าระวังและประตูวาร์ป; ยกจุดมองกล้องขึ้น 1H และขยับมุมมองไปทางตะวันตกชั่วคราวใกล้ประตู เพื่อให้ส่วนบนของวัตถุสูงและกรอบประตูอยู่ในเฟรม. การตรวจมุมใช้จุดเริ่มทดสอบ ไม่ใช่การเดินค้างจากจุดกลาง.
- viewport ที่ทดสอบเล็กกว่าแมปทั้งสองแกน จึงเลื่อนกล้องได้; กรณีแมปเล็กกว่าหน้าจอยังไม่เกิดใน layout นี้.
- collision ใช้ footprint แถบฐานโดยประมาณ ไม่ใช่ polygon ตาม alpha; ยังไม่มีระบบ safe-zone เชิง gameplay. การเปลี่ยนแมปทำงานได้เมื่อฉากปลายทางถูกเพิ่มและลงทะเบียน; ฉาก #4 สะพานเก่ายังไม่มี brief/asset จึงยังเข้าเล่นไม่ได้.
- ต้นไม้ใช้ trunk ที่เรียง depth ตามฐาน และ canopy อยู่ชั้นภาพเหนือผู้เล่นตาม asset manifest.
- ต้นไม้ trunk/canopy แยกไฟล์และจัดแนวในฉาก runtime ตามพิกัดประกอบ.
- ภาพตรวจสัดส่วนเป็นภาพประกอบจาก image generation จึงไม่ใช่การ compositing พิกเซลจริงและไม่ใช่หลักฐานการทดสอบใน runtime.
- ขอบ texture grass/road ยังอาจเห็นรอยต่อ; ตรวจภาพใน runtime เบื้องต้นแล้ว แต่ยังไม่ได้ทำ seam test แบบละเอียด.
